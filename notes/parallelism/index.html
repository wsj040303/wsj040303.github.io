并行计算

并行总览

为什么需要并行、五种切法分别切什么，以及 All-Reduce、All-Gather、All-to-All 和 P2P 的通信地图。

数据并行 DP

复制模型、切分 batch；从 DDP 的梯度 All-Reduce 到 ZeRO-1/2/3 与 FSDP 的状态分片。

张量并行 TP

Megatron 的列并行与行并行、Attention 按头切分、每层四次 All-Reduce 与 NVLink 域约束。

流水线并行 PP

GPipe、1F1B、交错式调度的时序，气泡公式，以及激活值显存从 O(m) 到 O(p) 的取舍。

专家并行 EP

MoE 的稀疏激活、Dispatch/Combine 两次 All-to-All、EPLB 负载均衡与 DeepEP 低延迟内核。

序列与上下文并行

Megatron 序列并行、Ring Attention 与 Ulysses：长序列下激活显存和通信量的两种解法。

组合与选型

把 DP、TP、PP、EP、CP 组合成 world size，对照 GPT-3、MT-NLG 与 DeepSeek-V3 的真实配置。

写给博客读者

不用公式，用餐厅、医院和长文章的类比，讲清五种并行各自解决什么问题，以及新闻里的并行配置怎么读。

这一组文章不绑定某个框架。每篇先讲清“切的是什么、通信多少、显存省在哪”，再落到 Megatron、DeepSpeed、PyTorch FSDP 和 DeepSeek 的实现与公开配置；文末列出 NVIDIA 官方文档、论文和中文博客，便于回查。
