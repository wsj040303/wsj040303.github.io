本文精读 Dao 等人的 FlashAttention: Fast and Memory-Efficient Exact Attention with IO-Awareness（arXiv v2，2022），重点解释注意力矩阵为何造成显存读写、分块后如何保持 Softmax 的完整归一化、反向传播为何重算，以及论文的复杂度与实验分别支持什么结论。读者只需了解矩阵乘法和 Transformer 中 token 的基本含义。文中图表与数字均来自论文原文，没有重新运行 GPU 基准测试。

主要工作

FlashAttention 是一种 IO 感知的精确注意力算法：它仍计算给定掩码及缩放规则下的 softmax⁡(QKT)V\operatorname{softmax}(QK^{\mathsf T})Vsoftmax(QKT)V，但把查询、键和值分块，在 GPU 片上存储中生成并消费局部注意力分数，不把完整的 N×NN\times NN×N 分数矩阵与概率矩阵写入高带宽显存（HBM）。片上存储容量小，无法容纳所有键时，算法以每行的最大值、指数和及部分输出为状态，逐块完成同一个 Softmax。训练时再根据输入和这些状态重算局部概率，避免为反向传播保存二次方大小的矩阵。论文，§1、§3.1、算法 1、附录 B

论文给出前向算法的片外访问量 Θ(N2d2/M)\Theta (N^{2}d^{2}/M)Θ(N2d2/M)：NNN 是序列长度，ddd 是单头维度，MMM 是以元素数计的片上存储容量；作为对照，文中的标准实现需要 Θ(Nd+N2)\Theta (Nd+N^{2})Θ(Nd+N2) 次访问。这改变的是数据搬运量与中间结果占用，稠密精确注意力的主要矩阵乘法仍要处理 N2N^{2}N2 对查询和键。论文在特定 A100、模型及基线条件下报告 BERT-large 端到端训练时间由 20.0 分钟降到 17.4 分钟，GPT-2 medium 由 Hugging Face 基线的 21.0 天降到 6.9 天。两个结果属于不同实验，不是一个通用加速系数。论文，§3.1–3.2、表 1–2

GPU 的高带宽显存（HBM）容量大，片上静态随机存取存储器（SRAM，包括共享内存等用于局部计算的片上资源）容量小、带宽高。论文以 A100 为例：HBM 容量为 40–80 GB，带宽约 1.5–2.0 TB/s；每个流多处理器有 192 KB 片上 SRAM，片上带宽估计约 19 TB/s。这里的 IO 指 HBM 与片上存储之间的数据读写。判断运算是否受显存带宽限制，还要看算术强度：每读写一个字节所完成的运算量。如果搬运数据期间不足以让计算单元持续工作，运行时间就主要由数据搬运决定。论文，§2.1、图 1

标准注意力中的两次矩阵乘法可以具有较高的算术强度；夹在两次乘法之间的 Softmax 则要读取 N×NN\times NN×N 的分数矩阵 SSS，对每行求指数、归约并归一化，再写出同样大小的概率矩阵 PPP。这类逐元素和归约操作对每次数据读写所做的计算较少，因此更容易受 HBM 带宽限制。论文以 GPT-2 的 N=1024N=1024N=1024、d=64d=64d=64 为例：SSS 或 PPP 各有 1,048,576 个元素，而单个 QQQ 矩阵有 65,536 个元素。标准实现需要让这两张较大的中间矩阵在各阶段进出 HBM。因此，论文将注意力中的部分或多数操作归为内存受限；两次矩阵乘法仍可能受算力限制。论文图 2 中计算量增加、HBM 读写减少而运行时间下降的对照，也支持这一分析。论文，§2.1–2.2、图 2

问题定义

论文的标准实现先算 S=QKTS=QK^{\mathsf T}S=QKT 并把 SSS 写入 HBM，接着读 SSS 求 P=softmax⁡(S)P=\operatorname{softmax}(S)P=softmax(S) 并写回 PPP，最后再读 PPP 与 VVV 求 O=PVO=PVO=PV。SSS、PPP 都有 N2N^{2}N2 个元素；训练反向传播还要使用中间概率。因而这个实现除输入和输出外，需要随序列长度平方增长的中间存储和显存访问。多头和批量处理会把这些成本乘上相应的头数与批量数。论文，§2.2、算法 0

FlashAttention 要同时满足两项约束：前向不能预先看到一整行 SSS，却要得到对整行归一化后的精确输出；反向不能保存整张 PPP，却要能计算 Q,  K,  VQ,\;K,\;VQ,K,V 的梯度。精确在此指算法不因跳过注意力位置而改变所定义的稠密注意力运算；有限精度计算、归约次序与具体内核仍可能造成数值差异。论文另设的块稀疏扩展会跳过指定块，计算的是由稀疏掩码定义的注意力，不能与稠密精确版本的语义混同。论文，§3.1、§3.3、附录 B

反向重算与存储代价

训练反向传播面临一个问题：前向为了节省显存，没有把整张注意力概率矩阵 P=softmax⁡(QKT)P=\operatorname{softmax}(QK^{\mathsf T})P=softmax(QKT) 存入 HBM；反向却要从输出梯度 dOdOdO（损失函数对 OOO 的导数）计算输入梯度 dQ,dK,dVdQ,dK,dVdQ,dK,dV。以下梯度关系以不含 Dropout 的注意力为例。因为 O=PVO=PVO=PV，值的梯度为 dV=PTdOdV=P^{\mathsf T}dOdV=PTdO，需要各位置的概率权重 PPP；计算 dQ,dKdQ,dKdQ,dK 时，梯度也要经过 Softmax 和分数矩阵 S=QKTS=QK^{\mathsf T}S=QKT。如果前向为此保留 N×NN\times NN×N 的 PPP，前向省掉的二次方中间存储就会重新出现。论文，§3.1、附录 B.4

FlashAttention 的办法是在反向传播需要某一块概率时才重算这一块。前向已经留下输入 Q,K,VQ,K,VQ,K,V、输出 OOO，以及每个查询行处理完全部键后的最大值 mmm 和指数和 ℓ\ellℓ。反向取出一对查询块与键/值块，先在片上重算 Sij=QiKjTS_{ij}=Q_iK_j^{\mathsf T}Sij​=Qi​KjT​，再对块内第 aaa 行、第 bbb 列恢复概率：

Pij[a,b]=exp⁡ ⁣(Sij[a,b]−mi[a])ℓi[a].P_{ij}[a,b] =\frac{\exp\!\left(S_{ij}[a,b]-m_i[a]\right)}{\ell_i[a]}.Pij​[a,b]=ℓi​[a]exp(Sij​[a,b]−mi​[a])​.

这里必须使用前向最终保存的 mi[a],ℓi[a]m_i[a],\ell_i[a]mi​[a],ℓi​[a]：它们覆盖整行所有键，所以恢复出的 Pij[a,b]P_{ij}[a,b]Pij​[a,b] 是完整 Softmax 在该位置的概率，而不是只在当前键块内部归一化的权重。论文，§3.1、附录 B.4、算法 4 第 10–13 行

局限性

稠密 FlashAttention 减少片外读写与中间存储，却仍计算所有允许的查询–键配对，时间主项仍随序列长度平方增长。真正跳过配对的块稀疏 FlashAttention 需要预先给定稀疏掩码；若非零块比例为 sss，论文给出 Θ(Nd+N2d2s/M)\Theta (Nd+N^{2}d^{2}s/M)Θ(Nd+N2d2s/M) 的访问量。它的输出精确对应该稀疏掩码定义的注意力，与不加稀疏掩码的稠密注意力不同。论文，§3.3

片上容量、线程资源与块大小限制了可直接应用的分块形状；论文图 2 已展示访问下降后运行时间受其他因素制约。作者还指出，针对新的注意力变体编写 CUDA 内核需要较多工程工作，实现在不同 GPU 架构之间可能需要调整；单 GPU 的 HBM–SRAM IO 分析也没有计入多 GPU 通信。本文依据论文中的 A100 实验判断其结果，没有复现其他设备、框架版本或推理服务负载的性能。论文，§3.2、§5

结论

FlashAttention 把注意力的性能问题从“只减少算术运算”扩展为“同时安排片上计算与 HBM 读写”：分块只临时生成局部分数，在线 Softmax 用最大值、指数和与部分输出维持整行归一化，反向重算局部概率而不保存整张矩阵。论文的 IO 分析给出所述内存模型下的访问量，A100 实验展示计算量可略增而注意力耗时下降；端到端训练和长上下文任务结果则说明这种算子优化在特定模型与负载中能转化为实际收益。评估其他场景时，仍需分别核对序列长度、头维度、片上容量、掩码、数值精度和对照实现。

为什么 K/V 块位于外循环，Q 块位于内循环？

为什么要计算 mmm、ℓ\ellℓ 和 OOO 这些行状态？

普通实现先把完整的 N×NN\times NN×N 分数矩阵 SSS 写到 HBM；计算 Softmax 时可以读取某一查询对应的整行分数，一次得到行最大值、指数和及所有概率。它也可以为数值稳定性计算行最大值，区别在于无需跨键块持续保存并更新这个值。FlashAttention 不保存整行 SSS，当前只能看到一个分数块，后续键的分数和最终 Softmax 分母尚未知，因此必须为每行留下足以合并下一块的状态。论文，§2.2、§3.1

mmm 记录已处理分数的最大值，供新块到来时把旧、新指数换到共同基准；ℓ\ellℓ 记录这个基准下的指数和，供归一化；OOO 保存对已处理键归一化后的部分输出。以前文计算示例为例，先处理分数 [1,2][1,2][1,2] 时基准最大值是 222，再处理 [3,0][3,0][3,0] 时最大值升到 333。旧块的指数和，以及从 ℓO\ell OℓO 还原出的未归一化加权和，都要乘 e2−3=e−1e^{2-3}=e^{-1}e2−3=e−1 才能与新块相加。缺少 mmm 就无法求这个换基系数，缺少 ℓ\ellℓ 就无法求共同分母，缺少部分输出就会丢失已处理值向量的加权贡献。最终的 m,ℓm,\ellm,ℓ 还使反向传播可以按块恢复完整 Softmax 的概率。论文算法 1 第 10–13 行、附录 B.4
